# LANCommander 2.1.10 Release Notes

:::info Full Release Notes
This is a patch release for the **2.1 series**. For the complete feature overview and all patch notes, visit the [LANCommander 2.1.0 release notes](./2.1.0).
:::

## Improvements
- Windows binaries are now code-signed as part of the release process, reducing SmartScreen and antivirus warnings on install.
- Updated AntDesign to the latest version.

## Bug Fixes
- Fixed standalone mods so uninstalling them no longer removes the base game. Only mods and expansions that share the base game's install directory can clean up orphaned base game files.
