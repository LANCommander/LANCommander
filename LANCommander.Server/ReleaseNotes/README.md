# Server release notes

Each release of the server has its own markdown file here, named for the release without a
prerelease label: `2.3.0.md`. The files are embedded in the server and read with
`LANCommander.SDK.Updating.ReleaseNotes`.

- Write the file for the upcoming release as changes land. Release candidates of 2.3.0 show
  `2.3.0.md`, so the notes can grow through the release candidates.
- Write for server administrators. The version is shown as a heading, so start with the content.
- These are the server's notes only. The launcher keeps its own in `LANCommander.Launcher/ReleaseNotes`,
  and the full release notes live on https://lancommander.app.
